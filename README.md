# ExamArena

**ExamArena** — это веб-приложение для подготовки к ЕГЭ в формате тренировки и соревновательных дуэлей 1 на 1.  
Проект позволяет решать задания по выбранным предметам и темам, соревноваться с другими пользователями в реальном времени и отслеживать личный прогресс и рейтинг.

**Доступ к запущенному сайту:**  
https://examarena.wuspie.org/
---

## Установка

### 1. Клонирование репозитория
```bash
git clone https://github.com/Qb1Le/-No-1-
cd ExamArena
```

### 2. Активируйте venv
**Windows (PowerShell):**
```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
```

**Windows (CMD):**
```cmd
python -m venv venv
venv\Scripts\activate
```

**Linux/Mac:**
```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Установите зависимости
```bash
pip install -r requirements.txt
```

## Запуск

```bash
python app.py
```

Сайт будет доступен по адресу: `http://localhost:5000`
